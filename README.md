# Bellas Boutique (DIHC)
Requisitos: Node 18+.
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # compila y revisa tipos
Datos y lógica simulados en localStorage (sin backend). Para reiniciar los datos: borra `bellas-db` en localStorage.
